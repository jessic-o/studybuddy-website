# StudyBuddy Website

Class project site for **StudyBuddy** — a phone-locking study device + campus productivity app.

**Team:** Heather Hoang, Leah Loza, Jessica O’Bonna, Erica Skelly

## Live link

**https://jessic-o.github.io/studybuddy-website/**

Submission PDF: `submission/StudyBuddy_Finalized_Website.pdf`

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Pages

- Home, About, Product, Pricing, Checkout (payment portal)
- Testimonials, FAQ, Contact
- Privacy Policy, Business Policies
